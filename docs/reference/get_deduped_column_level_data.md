# Get column names de-duplicated and in the correct order

Get column names de-duplicated and in the correct order

## Usage

``` r
get_deduped_column_level_data(cansimTableNumber, language, column)
```

## Arguments

- cansimTableNumber:

  The table number

- language:

  The language of the column names

- column:

  The column name

## Value

A tibble with the column names
